# 0.4.0（10）本地学习闭环

本版在原 iOS 项目上连接 PGN、规则证据、针对性练习和不同局面的到期复测。只支持一个窄主题：**漏走当时可一步将死的着法**。没有发现此类型不代表没有其他问题，也不把未走一步杀自动判成败着：实际走法仍可能获胜。

## 使用

1. 棋谱 → 导入 FEN / PGN → PGN → 粘贴或选择一盘文件。导入页返回后点“关闭”。原始 PGN、备注和完整本地导出沿用原入口。
2. 棋谱 → 从我的棋谱找练习 → 选择棋谱 → 明确选择执白或执黑 → 在本机检查。不会按 PGN 姓名猜测身份；可更正颜色后重新检查。
3. 查看当时局面、实际走法、所有一步杀答案与实际走法后的合法应对，选择最多两处建立练习。没有规则证据时不制造弱点，也不自动推荐无关题。
4. 完成一题针对性练习；实际完成时间后 24 小时可做不同的新局面复测。提前练、提示、原题重试、针对性练习和首次独立提交分别保存。跨日自动化使用注入时间，不声称已真实等待数天。
5. 在时间胶囊中导出棋谱、用户原话、规则证据、题目定义/版本/来源、暴露记录和复习记录。没有新增云端或账号权限。

## 证据与重复判定

本机 bundled chess.js 按主线重放，保留王车易位、吃过路兵、走棋方和完整历史。枚举当前所有合法走法，确认将军且对方合法应将数为零，再与实际走法比较。检测不依赖 PGN 的 `#` 注释、随机题或 AI 心理推测。非法、取消或终局后的走法不产生部分成功结果。

至少两盘不同棋局、两个不同局面有证据，才显示重复证据。棋谱指纹由起始 FEN 的前四字段与完整主线 UCI 计算，重复导入和只改计步字段不会凑次数；同一记录改动主线后旧扫描不计当前汇总。这仍不能证明某个思考习惯或因果弱点。扫描覆盖仅限主动选择过的棋谱与执棋方。

规则证据与用户原话分开保存。已有同局面理由可连接证据而不覆盖候选着、理由、记录时机或原练习项；没有记录就保持空白。标签可改为“不适用”。原有主动记录和跳过能力保留。

## 题目与复习限制

沿用 5 道原创、逐题枚举合法答案验证的一步杀题；来源、原许可和版本随题保存。所有练习是白方走，训练同一将死规则，不声称模拟原对手或覆盖其他错误类型。测验题排除本机棋谱、原有教学题和已经展示的局面；“未见过”仅指这些本机记录，无法知道其他网站或设备的经历。去重忽略 FEN 计步字段，保留走棋方、王车易位和吃过路兵状态。用尽或没有合格题时显示待准备，不生成未经验证的谜题。

提交前隐藏答案、评分与变化线；先保存曝光/提示记录再显示。首次答案不可覆盖。针对性练习完成后 +24 小时；到期不同新题首次无提示答对，显示一次独立通过并安排 +3 天，再次通过 +7 天。用提示、答错、提前或原题不增加独立通过，按完成时间 +1 天。跳过不伪造对错。进度不等于掌握习惯、提高 Elo 或人格/健康测评。

## 数据和回滚

沿用 `games-v1.json` 与 `decisions-v1.json`。DecisionArchive schema 1 新增可选 scans，DecisionNote 新增可选 evidence，旧记录可读取；TimeCapsule schema 2 包含完整归档。新版本原子写入失败不显示成功，损坏存储不覆盖。没有新增外部传输、账号、追踪、通知权限或支付。

代码回滚点 `d889ba1`，备份分支 `backup/pre-learning-loop-20261023`。回滚前先导出并备份实际用户数据：旧版再次保存时可能丢弃它不认识的可选字段。测试使用独立 ui-test 文件和临时目录。

## 验收依据

自动测试覆盖棋规答案、颜色选择、去重、重复证据、旧记录兼容、用户原话保留、原子写入、导出关联、实际完成时间、提示/首次答案/提前练/原题和无合适题降级。手机流程包括手动 PGN、证据到练习、注入跨日后的不同新题、重启保留，以及完整公开真实 PGN 没有该主题证据时的诚实显示。

真实 PGN 来源：[PGN Mentor 的 1972 世界冠军赛记录](https://www.pgnmentor.com/events/WorldChamp1972.pgn)。本轮在测试工作目录使用公开记录，没有上传用户个人棋谱；正例闭环采用标明 Synthetic 的合法构造样本，不能当作用户的真实错误证据。最终测试数量、签名包、提交和 Apple 状态分别见本次交付记录，编译通过不等于外部 TestFlight 可安装。
