# 0.4.3（13）TestFlight 验收说明草稿

此构建保留 0.4.2 的 12 个条件局面和 4 个延后题，新增个人 PGN 本地证据流程。旧 0.4.2（12）归档及 IPA 保留作回滚；不另外上传。上传新包不代表外部测试者已可安装，也不修改 0.4.0 的独立审核。

## 测试路径

学习首页 →「体验一局 / 导入我的 PGN」→「体验一局 · 实际本地分析」。这是明确标注的完整构造棋谱；运行本机 Stockfish，不发送棋谱到服务器。先提交两题，或明确结束，再看棋规事实、所有一步将死答案、合法替代分支和双预算引擎证据。候选着和理由可跳过，首答不覆盖，反馈后的回忆单独保存。

随后做一题匹配练习。个人记录从实际完成时起等待 24 小时，再提供两题本机未见且排除近重复的复测题。示例可明确模拟到期；模拟及提示成绩排除于个人独立表现。有限题库不足时明确停止，不用示例冒充个人生成。完整时间胶囊包含所有证据、题源版本、题序、首答、提示和排除原因；未结束轮次需先明确结束以防导出泄露答案。

也可粘贴或手动导入自己的单盘 PGN，确认执棋颜色。支持标准起始局面、主线最多 200 半回合 / 原文最多 200 KB；原注释与变例保存但不分析。非标准 FEN 起始、变体、多盘及超限会拒绝，不静默截断；旧 FEN/PGN 导入入口继续保留。

## 已知范围

仅检测漏走一步将死，最多验证前三处候选、每处前两个合法替代分支，最多生成一组。替代分支不是严格单因素实验；匹配练习来自已有有来源的题库，不是从个人棋谱伪造的反事实。无法从单盘断言人的心理原因，不能诊断任意弱点，不证明提高棋力、Elo 或长期掌握。

正例验收使用构造棋谱，真实公开棋谱用于无支持证据路径。跨日验收使用注入时间；尚无真实学习效果研究。无云备份、第三方账户导入、后台追踪或新系统权限。当前整包导出不提供整包恢复入口。
