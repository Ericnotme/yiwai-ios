# 条件对照实验（本地 0.4.2 / 12）

这是自愿的一步将死练习原型。记录用户提交的走法和可选候选着/威胁自述，不测量注意力，不推断心理盲区，不证明迁移效果或棋力提升。界面明确说明：这些记录只说明你提交了什么，不能完整反映你当时看到了什么。

## 内容与验证

`Resources/condition-catalog.json` 定义三种不同结构：后象协同、王前斜线、被牵制兵。每组四条件：A/B 原防守（唯一一步杀），C/D 防守改变（无一步杀）；B/D 有指定合法且非将死的吃子着，A/C 无该吃子机会。每组关键着在四局面都合法。并非控制了所有其他变量，不作因果解释。后象组的 a/d 兵位置等伴随差异在合法证明中可见。

四个延时局面（两题有一步杀、两题无）使用不同结构与实际局面。其中包含经典 Légal 将死、Opera game 的底线结构；不宣称棋型或历史走法原创。题库仅包含本项目选编的走法、条件说明和验证数据，无抓取第三方注释。项目自身说明与数据沿用 GPL-3.0-or-later；chess.js / Stockfish 许可证和来源不变。

每题有从标准初始局面开始的合法 PGN、UCI 证明链、精确 FEN 和全部一步将死答案。`ConditionRules` 重放整条证明，并枚举所有合法下一步：对手被将军且无合法应对才算将死；逼和不算。`ConditionContentTests` 再运行 App 内置 Stockfish，保存带内容 SHA-256 的复核证据。运行时缺少证明、答案不符或引擎证据失配，则整组不开放。内容不自动生成、不自动修改用户 FEN。

## 作答与解释

- 12 题保存显式题序、64 位随机种子和四种 Williams 条件序列索引，每轮交错三个结构。不同题序不等于随机对照研究。
- 可跳过可选文字，可暂停/恢复。首次提交使用持久 UUID 幂等保存；相同重试不重复写入，改答案被拒绝。反馈后重试和补记另存，不能覆盖首答。
- 不显示条件名、标准答案、分数或变化线，直到 12 题完成或用户明确选择“结束并查看”。未提交是缺失，不算错误。提前反馈将整组题标记曝光，后续相关首答被排除。
- 演示、已见、用户主动标记参考提示、反馈后记录不计独立条件比较。候选着自述不是注意力测量。
- 至少三组完整、无排除、同方向模式才显示暂定棋规练习提示。否则明确证据不足；同时列出相反/不足证据。不计算显著性或提升百分比。
- 延时复测从实际结束时刻 +86,400 秒起开放。四题必须全都未在本机棋谱、展示记录和内置已知局面中出现；否则明确“待准备”。只保证本机记录范围的未见，不保证人生中未见。FEN 去重忽略两项计步数，保留执棋方、易位权与过路兵状态。
- 测试时钟只在 Debug UI 测试条件下可注入，导出注明时钟来源；Release 正常运行用设备时间。测试跨日不代表实际等待了一天。

## 数据与回滚

新增 `Application Support/YiwaiPractice/conditions-v1.json`，与原棋谱、决策记录并存；不迁移或覆盖原文件。JSON 原子写入失败不确认答案；读取损坏时保留原文件并禁止写入。曝光先写入共用已见清单，失败时不展示题目；意外中断最多保守地把题排除，不会错误声称未见。

时间胶囊 schema 3 增加可选 `conditionStudy`，内部 schema 1。保存题目快照及引擎证据、顺序、首答/自述、时间、排除、反馈、补记、重试和曝光。旧 schema 2 仍可解码。完整导出会含答案，因此进行中先询问是否明确结束，不静默暴露。原独立学习示例导出不混入个人条件记录。无新增云服务、凭据、收集 SDK 或系统权限。

回滚基线为本地 0.4.1 提交 `9f53dbb`，备份分支 `backup/pre-condition-study-20261024`；0.4.0 签名工件保留。回退源码不会删除新 JSON，但旧 App 不认识此功能；共用已见标记保守保留。不要删除用户记录或倒退 App Store 构建号。

## 验收与限制

验收包含 16 题 PGN 合法性、完整答案、Stockfish 一致性；首答重试/中断恢复；统一反馈与无障碍标签无泄露；演示/提示/缺失/已见排除；三组一致及反例；真实时间边界和题库耗尽；完整导出、旧 PGN/FEN/离线对弈/原复习回归；iPhone / iPad 横竖屏与大字。

只有三种结构及四题延时题，首次用完后无持续新题供应。没有心理测量、学习效果实验或真实人群数据；所有自动化使用合成记录，跨日验证使用注入时间。尚无整包导入恢复入口。此版本本地验收后再决定发布，不改变正在审核的 0.4.0。
