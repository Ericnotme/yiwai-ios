# 弈外 · iPhone 原生版

离线人机对弈、棋题、棋谱回放和中文复盘。此仓库提供 **0.3.3（6）** 的完整应用源码、适配层、资源、测试、Stockfish 对应源码与构建材料。

**源码公开不表示 TestFlight 已发布。** 本版已完成本地测试和签名归档；上传、Apple 处理、外测审核及安装是独立阶段。

- 对弈：原创 Seed 0.2，棋力未评级。
- 复盘：未修改的 Stockfish.js 19.0.0 lite single，在本地 WebKit Worker 中运行。
- 教练：依据合法变化线与棋规生成中文解释，不是大模型对话。
- 准确度：沿用弈外网站的计算口径，不声称与 Lichess/Chess.com 完全一致；限时搜索会受设备影响。
- 数据：棋局和笔记只保存在本机，没有账号、云端 API 或分析上传。

## 0.3.3 修复

修复保存的长棋谱再次打开时长时间停留在“载入完整棋谱”的问题。旧读取路径为每条推荐和实际应对变化重新生成从开局开始的所有棋盘快照。现在仅遍历原棋谱一次，逐条校验最多 12 手的变化后撤回，保留三次重复、五十回合、王车易位、吃过路兵等完整棋规状态。缓存读取不再和人机搜索共用串行队列。

同一页面的读取请求只启动一次；离开页面或进入后台会取消旧读取，重返前台可以继续加载。过期回调不会覆盖新结果。已有棋谱、错题本和已保存报告均保留，不通过删除缓存绕过校验。

保留 0.3.2 的 WebKit 短 Worker 地址修复和 0.3.1 的精确评分/变化线一致性修复。上游 Stockfish JS/WASM 仍未修改。

## 本版验证

32 项 JavaScript 测试和 23 项公开 Release 原生测试通过。公开回归使用生成的 120 手合法棋谱验证快速/细致缓存、重复进入、取消旧读取和无效缓存拒绝；另以受影响的 78 手实机保存报告做私有对照，不公开个人棋谱。原生缓存读取从约 8.7 秒降至约 0.40–0.42 秒；这是 Release 模拟器测量，不能替代新版实机验收。原 78 手报告的 Release 界面回归也已通过：细致缓存冷启动、反复进入和返回、取消重分析后保留完整报告、快速重试完成，以及快速报告冷启动读取。
