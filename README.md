# 弈外 · iPhone 原生版

离线人机对弈、棋题、棋谱回放和中文复盘。此仓库提供 **0.3.2（5）** 的完整应用源码、适配层、资源、测试、Stockfish 对应源码与构建材料。

**源码公开不表示 TestFlight 已发布。** 本版已完成本地测试和签名归档；上传、Apple 处理、外测审核及安装是独立阶段。

- 对弈：原创 Seed 0.2，棋力未评级。
- 复盘：未修改的 Stockfish.js 19.0.0 lite single，在本地 WebKit Worker 中运行。
- 教练：依据合法变化线与棋规生成中文解释，不是大模型对话。
- 准确度：沿用弈外网站的计算口径，不声称与 Lichess/Chess.com 完全一致；限时搜索会受设备影响。
- 数据：棋局和笔记只保存在本机，没有账号、云端 API 或分析上传。

## 0.3.2 修复

修复较新 iOS WebKit 无法启动离线复盘引擎的问题。旧适配层把 WASM 编码进 Worker URL 的片段，长度为 2,552,627 字符；实机对照确认 2,097,152 字符可加载、2,097,153 字符被拒绝。现在将原始 WASM 字节保存在本地 Blob，只传递短资源地址；完成、取消和启动失败时均释放资源。CSP 仅允许该离线 Blob 连接，不开放网络分析服务。启动失败与搜索中断也有不同错误标识。

保留 0.3.1 的精确评分/变化线一致性修复及棋谱重新打开修复。上游 Stockfish JS/WASM 仍未修改。
